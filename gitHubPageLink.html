GitHub Pages로 웹사이트 배포하기

깃허브(GitHub)의 무료 호스팅 서비스인 GitHub Pages를 이용하면 정적 웹사이트를 쉽고 빠르게 무료로 배포할 수 있습니다.
아래의 4단계를 차례대로 따라 진행해 보세요.

01

저장소(Repository) 생성하기

  • GitHub에 로그인한 후 우측 상단의 '+' 아이콘을 눌러 'New repository'를 선택합니다.
  • 저장소 이름(Repository name)을 입력합니다.
  • 반드시 Public(공개)으로 설정해야 무료 배포가 가능합니다.
  • 'Add a README file'에 체크한 뒤 'Create repository'를 누릅니다.
02

웹사이트 파일 업로드하기

  • HTML 기본 파일인 index.html 파일을 저장소 루트(최상단) 디렉토리에 업로드하거나 생성합니다.
  • index.html이 웹사이트의 첫 화면(진입점) 역할을 합니다.
03

GitHub Pages 활성화하기

  • 생성한 저장소 페이지 상단의 Settings(설정) 탭을 클릭합니다.
  • 왼쪽 메뉴에서 Pages를 선택합니다.
  • Build and deployment 섹션의 Branch 설정을 None에서 main(또는 master) 브랜치와 루트 폴더(/ (root))로 변경합니다.
  • Save 버튼을 누릅니다.
04

배포 완료 확인하기

  • 1~2분 정도 기다린 후 페이지를 새로고침하면 상단에 배포된 웹사이트 주소(https://<사용자이름>.github.io/<저장소이름>)가 나타납니다.
  • 해당 주소를 클릭해 웹사이트가 정상적으로 배포되었는지 확인합니다.

내 배포 주소 미리 생성해보기

사용자 이름과 저장소 이름을 입력하면 실제로 발급될 최종 웹 주소를 확인할 수 있습니다.

최종 서비스 URL: https://<사용자이름>.github.io/<저장소이름>
