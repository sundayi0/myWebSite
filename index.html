Project Lifecycle

웹 기획 및 구축의 5단계 로드맵

현업 프로젝트가 진행되는 표준 순서와 핵심 산출물입니다.

PHASE 01

요구사항 정의

프로젝트 목적, 타깃 사용자 분석, 서비스 핵심 기능 목록화

산출물: 기능정의서
PHASE 02

정보구조(IA) 설계

사용자 이동 동선(User Flow)과 메뉴 트리 구조 체계화

산출물: 메뉴구조도(IA)
PHASE 03

화면 UI/UX 기획

컴포넌트 배치, 인터랙션 및 예외 처리 정책 구체화

산출물: 와이어프레임(SB)
PHASE 04

프런트엔드 구축

웹 표준 HTML5, CSS3 반응형 레이아웃, JS 동적 로직 구현

산출물: 소스 코드
PHASE 05

검증 및 클라우드 배포

크로스 브라우징 및 검수 후 GitHub Pages를 통한 실제 론칭

산출물: 서비스 URL

Architecture & Tech Stack

웹 구축을 지탱하는 기술 요소

기획서 상의 아이디어를 실물 소프트웨어로 번역하는 3대 언어와 인프라

HTML5 (골격)

콘텐츠의 논리적인 의미와 구조(Semantic Tag)를 규정하는 뼈대

<header>, <main>, <form>

CSS3 / Tailwind (시각화)

기획된 UI 레이아웃, 여백, 컬러 시스템 및 모바일 반응형 렌더링

flex, grid, media-query

JavaScript (동작)

변수, 연산자, 이벤트 핸들링으로 사용자 상호작용과 계산 처리

let, const, addEventListener

GitHub Pages (호스팅)

버전 관리와 협업, 그리고 웹 서버 없이 무료로 도메인을 발급받아 배포

git push -> *.github.io
